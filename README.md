# A2NetOps 2027 Workshop Website

Public website for **Agents for Autonomous Network Operations: Causal Reasoning, Uncertainty, and Safe Action**, a one-day workshop at AAAI-27 in Montréal, Canada.

Website: <https://a2netops.github.io/>

## Local preview

From this repository:

```bash
python3 -m http.server 8765
```

Then open <http://127.0.0.1:8765/>.

The site is plain HTML, CSS, and JavaScript and is published from the `main` branch through GitHub Pages.

## Hero artwork

The current concept artwork is an original generated placeholder stored at
`assets/hero-autonomous-netops.jpg`. It contains no text or third-party logos
and can be replaced later with another wide image of roughly 2:1 aspect ratio.
